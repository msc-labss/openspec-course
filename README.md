# OpenSpec course: the companion repository

The demo project of the free OpenSpec course on the
[MSC Labs YouTube channel](https://www.youtube.com/@msclabs): six short episodes on
spec-driven development with [OpenSpec](https://github.com/Fission-AI/OpenSpec) and an AI
coding agent (Claude Code in the videos).

The project is **tasklog**, a tiny task list for the terminal. It has no dependencies.

    node src/cli.js add "write the spec"
    node src/cli.js list
    node src/cli.js done 1
    node src/cli.js remove 1

Tests: `npm test` (Node 22.12 or newer).

## Follow along

Each episode has a tag: the project as it is at the **end** of that episode. To start an
episode, check out the tag before it.

| Episode | What happens | Tag |
|---|---|---|
| start | tasklog before OpenSpec | `start` |
| 1 | [First setup](https://youtu.be/wm6H_v2THMg): install, `openspec init` | `ep1` |
| 2 | Your first change: propose (`/opsx:propose`, the proposal, spec and tasks) | `ep2` |
| 3 | From tasks to code: apply | later |
| 4 | Archive: specs become the record | later |
| 5 | Changing existing behaviour | later |
| 6 | OpenSpec on a real project | later |

    git clone https://github.com/msc-labss/openspec-course.git
    cd openspec-course
    git checkout start

The specs, proposals and code in the later tags were written by an AI agent from the
prompts shown in the videos, and are kept as it wrote them. Your own run will word things
differently; that is expected.
